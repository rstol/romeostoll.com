I developed a single page application for [Steuerladen GmbH](https://www.steuerladen.ch), a Swiss tax services company. The project focused on creating a responsive, content-rich web presence with efficient content management capabilities.

Goals:

- Design highlights Steuerladen's services while providing an intuitive user journey
- Modular content blocks for flexible storytelling
- Build for speed with optimized assets and efficient rendering

Technology stack:

- Next.js, Typescript, Tailwind CSS
- [Prismic CMS](https://prismic.io/) with slicemachine for fast content editing
- Custom server Node.js deployment on swiss servers
