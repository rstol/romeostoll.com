I designed and developed a new website for [Weingut Stoll](https://weingut-stoll.ch), my family's Swiss winery business in 2021/22. The project focused on modernizing their online presence and creating a mobile-first shopping experience.

## Project Overview

Built with React (Next.js) prioritizing speed, accessibility, and storytelling. Content management is handled through Prismic (headless CMS) with product data from Shopify's Storefront GraphQL API. This decoupled architecture enables quick content updates and complete design flexibility, while letting Shopify handle the checkout flow (payments) and act as an ERP system for product and customer data.

### Goals

- User Experience: Create a visually distinctive site with fast page loads
- Content & Branding: Enable effective storytelling through customizable content sections
- Ease of Use: Simplify content updates, product inventory management, and billing.

### Tech Stack

- Frontend: Next.js, TypeScript, Tailwind CSS
- CMS: Prismic with Slicemachine for modular content editing
- eCommerce: Shopify Storefront GraphQL API + Shopify Checkout
- Hosting: Vercel for performance optimization and automated deployment

### Results

- 78% traffic increase in the first six months
- Improved mobile usability
- Faster update cycles through intuitive content editing
